# RegressionLib — контракт бібліотеки (SDK)

**Версія API:** 1.0  **Версія DLL:** 1.0.0
**Призначення:** регресійний аналіз — підбір прямої `y = slope·x + intercept` методом найменших квадратів, прогноз, коефіцієнт детермінації R² та залишки.

## 1. Вміст пакунка

| Шлях | Призначення |
|---|---|
| `include/regression.h` | заголовковий файл (оголошення API) |
| `lib/RegressionLib.lib` | імпортна бібліотека (для **неявного** зв'язування) |
| `bin/RegressionLib.dll` | динамічна бібліотека (потрібна завжди) |
| `README.md` | цей файл — контракт |

## 2. Технічні умови

- Платформа: **Windows x64**, зібрано MSVC, конфігурація Release.
- Клієнт **повинен бути x64**. Підключення 32-бітної програми до цієї DLL завершиться помилкою (`ERROR_BAD_EXE_FORMAT`, код 193).
- Інтерфейс — **C-ABI** (`extern "C"`), конвенція виклику `__cdecl`. Імена експорту не декоровані: `linearRegression`, `predict`, `rSquared`, `residuals`, `regressionVersion`, `regressionErrorMessage`.
- Типи в інтерфейсі: лише `int`, `double`, вказівники на них та `const char*`. Класи, `std::string`, `std::vector` і винятки через межу DLL **не передаються**.
- Бібліотека **не має глобального стану**, функції можна викликати з різних потоків одночасно (якщо потоки не пишуть в один і той самий вихідний масив).
- Функції не викидають винятків і не записують нічого у файли чи консоль.

## 3. Загальні правила

1. Кожна функція повертає `int` — **код повернення** (таблиця в п. 4). `0` означає успіх.
2. Вихідні параметри (`slope`, `intercept`, `r2`, `result`, `out`) **змінюються лише при успіху**. Після помилки їхні значення залишаються такими, як були до виклику.
3. Усі вхідні числа мають бути **скінченними** (не `NaN` і не `±Inf`).
4. Пам'ять: бібліотека **нічого не виділяє і не звільняє**. Масиви виділяє та звільняє **викликач**. Єдиний виняток — рядки з `regressionVersion()` та `regressionErrorMessage()`: це вказівники на статичні рядки всередині DLL, їх **не можна** звільняти і змінювати.
5. Бібліотека **не може перевірити**, чи справді в масиві `n` елементів. Якщо вказати `n` більше за реальний розмір масиву, поведінка не визначена (Access Violation). Це відповідальність викликача.
6. Порядок перевірок: обов'язкові вказівники → кількість `n` → скінченність значень → особливі випадки. Повертається код першої виявленої помилки.

## 4. Коди повернення

| Значення | Ім'я | Значення |
|---:|---|---|
| 0 | `REGRESSION_OK` | успіх |
| 1 | `REGRESSION_ERR_NULL_POINTER` | один з обов'язкових вказівників дорівнює `nullptr` |
| 2 | `REGRESSION_ERR_INVALID_COUNT` | недопустима кількість точок `n` |
| 3 | `REGRESSION_ERR_INVALID_VALUE` | у даних (або в `slope`/`intercept`/`x`) є `NaN` чи `±Inf` |
| 4 | `REGRESSION_ERR_DEGENERATE` | розв'язку не існує: усі `x` однакові (для `linearRegression`) або усі `y` однакові (для `rSquared`) |
| 5 | `REGRESSION_ERR_OVERFLOW` | результат не вміщується в `double` |

## 5. Функції

### 5.1 `linearRegression`
```c
int linearRegression(const double* x, const double* y, int n,
                     double* slope, double* intercept);
```
Знаходить коефіцієнти прямої `y = slope·x + intercept`:
`slope = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²`, `intercept = ȳ − slope·x̄`.

| Параметр | Опис | Обмеження |
|---|---|---|
| `x` | масив значень x, `n` елементів | не `nullptr`, усі скінченні |
| `y` | масив значень y, `n` елементів | не `nullptr`, усі скінченні |
| `n` | кількість точок | **n ≥ 2** |
| `slope` | вихід: кутовий коефіцієнт | не `nullptr` |
| `intercept` | вихід: вільний член | не `nullptr` |

Помилки: 1, 2, 3, 4 (усі `x` однакові), 5.

### 5.2 `predict`
```c
int predict(double slope, double intercept, double x, double* result);
```
`*result = slope·x + intercept`. Усі вхідні числа мають бути скінченними, `result` — не `nullptr`. Помилки: 1, 3, 5.

### 5.3 `rSquared`
```c
int rSquared(const double* x, const double* y, int n,
             double slope, double intercept, double* r2);
```
`R² = 1 − SSres / SStot`, де `SSres = Σ(yᵢ − (slope·xᵢ + intercept))²`, `SStot = Σ(yᵢ − ȳ)²`.
Пряма задається викликачем (не обов'язково та, що знайшла `linearRegression`), тому `R²` **може бути від'ємним**, якщо вона гірша за пряму `y = ȳ`. Обмеження: **n ≥ 2**, усі `y` не можуть бути однаковими. Помилки: 1, 2, 3, 4 (усі `y` однакові), 5.

### 5.4 `residuals`
```c
int residuals(const double* x, const double* y, int n,
              double slope, double intercept, double* out);
```
`out[i] = y[i] − (slope·x[i] + intercept)`. Масив `out` виділяє викликач, у ньому має бути **не менше `n` елементів**. Обмеження: **n ≥ 1**. Помилки: 1, 2, 3, 5.

### 5.5 Службові функції
```c
const char* regressionVersion(void);              // "1.0.0"
const char* regressionErrorMessage(int status);   // текстовий опис коду
```

## 6. Граничні випадки (коротко)

| Ситуація | Результат |
|---|---|
| `x`, `y` або вихідний вказівник = `nullptr` | код 1 |
| `n = 0`, `n = 1` (для `linearRegression`/`rSquared`), `n < 0` | код 2 |
| `NaN` чи `Inf` у даних | код 3 |
| усі `x` однакові | код 4 |
| надвеликі значення (≈ 1e308) | код 5 |
| дуже великий масив (мільйони точок) | коректно, час пропорційний `n` |

## 7. Приклад використання

```cpp
double x[] = {1, 2, 3, 4}, y[] = {3, 5, 7, 9};
double a = 0, b = 0;
int st = linearRegression(x, y, 4, &a, &b);
if (st != REGRESSION_OK) { /* обробити помилку */ }
// a == 2, b == 1
```
